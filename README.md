# RKTRL (ReKontrol) — MIDI sequencer & controller for Android

//

1024 steps sequencer with pattern generator and fully editable steps.
128 assignables CC controls live editing with 1 fader.
Destroy Mode with 9 presets. 

// 

French and English languages.
Customisable interface (background and accent colors).
Customisable MIDI channels names. 
Possibility to export and load a save state.
